GRUPO MURILLO — DEMOSTRACIÓN WEB

Sitio estático sin base de datos ni cotizador. Abrir index.html para ver el contenido (para probar geolocalización se requiere HTTPS, por ejemplo al alojarlo en Netlify). Archivo ubicacion.html implementa la opción de rescate por operador o por tercero. El enlace de geolocalización pide permiso expreso al usuario y prepara un mensaje que debe enviarse manualmente en WhatsApp.

Antes de publicar como sitio oficial: validar redacciones de misión/historia/catálogo de servicios, verificar los derechos de publicación de fotografías, confirmar cobertura real del rescate 24/7, validar teléfono y dirección, revisar accesibilidad y política de privacidad apropiada.

Publicación gratis: en Netlify, crear proyecto nuevo y subir el contenido de esta carpeta (index.html, ubicacion.html, styles.css, script.js, assets/). No sobrescribir el proyecto existente de Lex Nova.
